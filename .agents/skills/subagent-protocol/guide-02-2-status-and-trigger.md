# Selection

Load this protocol when coordinating authorized specialists, maintaining a team
workflow, or diagnosing delegation. Load only the conditional guide needed for
the current decision. Ordinary single-agent work needs no team activation.

A child returns its scoped result to its coordinator. Nested delegation requires
explicit authorization or an applicable workflow requirement and must respect the
same ownership, budget, and host limits. A role label alone grants no delegation.

If visible panes are requested, inspect the host's supported viewing tools.
The same task IDs, handoff contract, and verification gates still apply.
