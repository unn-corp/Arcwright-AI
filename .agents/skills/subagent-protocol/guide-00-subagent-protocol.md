# Specialist orchestration

Use the entrypoint for dispatch, task tracking, and verification. Delegate when
the user or an invoked workflow authorizes substantial independent work. Complete
a small, focused task directly; a multistep task alone does not require a team.

Select the smallest suitable team preset when its roles and gates fit the task.
Read project context once and reuse it. Give each child a scoped capability brief
and accessible source evidence, rather than the full skill collection or chat.

Use actual host delegation tools. Host panes are an optional viewing surface when
requested, not a separate completion protocol. This skill's historical name does
not restrict the provider, model, or host.
