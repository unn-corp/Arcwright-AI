# Context health

Use host-reported context or usage data when available. Otherwise report usage as
unknown; do not infer remaining capacity from a profile, file count, or nominal
model window.

Reduce repeated context before introducing a handoff: reuse the capability brief,
reference accessible artifacts, and keep a short ledger of source identity,
decisions, unresolved findings, and next actions. Load conditional skill references
only when the current decision needs them.

When a real context limit threatens continuity, produce a compact handoff that
lets the next run reconcile active tasks and owned changes. Use the host's supported
continuation/compaction mechanism. Do not create an unrelated top-level thread or
persistent schedule merely because a guessed percentage was crossed. Byte-size
reductions are evidence of smaller files, not measured token or cost savings.
