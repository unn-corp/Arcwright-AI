# Wind down owned work

Reconcile every owned task and required gate. Record outcomes, source identity,
evidence, unresolved findings, and recovery paths before reporting completion.
Use the host's supported finish/shutdown/cancel lifecycle; a host may retain a live
native agent for follow-up, while a T3 review round ends as its own task.

Do not assume that an idle process ended, a prior session's ID is resumable, or a
storage thread is a new review round. Cancel only owned work that no longer needs
to run. Preserve unrelated tasks, visible panes, and recoverable worktrees. A
separate top-level conversation is created only at the user's explicit request.
