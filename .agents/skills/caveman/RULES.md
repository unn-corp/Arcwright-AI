# Caveman rules

- Activate only for an explicitly selected mode or requested artifact compression.
- Answer first; remove ceremony and filler. Clarity beats terseness.
- Preserve technical payloads, code, structure, facts, conditions, and negations.
- Use the user's language and the host's required tone, updates, and question format.
- Persist chat mode until disabled; keep artifact compression scoped to the request.
- Normal persisted writing keeps its required style unless compression was requested.
- Status does not activate a mode. No hooks or fixed token-savings claim.
- See [SKILL.md](SKILL.md) for levels, exceptions, and source notes.
