# React research rules

- Match the project's React version and verify uncertain behavior with relevant primary docs, tests/source, types, or design history.
- Reuse available context and source. A small lookup needs no clone or full investigation.
- If needed, keep owned source/research under the active Arcwright run; never use `.claude/react` or the installed skill as a workspace.
- Lenses are optional scopes, not a mandatory six-agent team. Authorized delegation uses actual host tools and the shared subagent protocol.
- Separate public contracts from internal details and report version/type discrepancies. Test work follows test-quality and existing fixtures.
