# Claude connector adapter

Read only when Claude is an intended client or its directory is the chosen
distribution target. Consult the relevant current pages in the
[official connector documentation](https://claude.com/docs/connectors/building/what-to-build),
not the full documentation export on every MCP task.

Check the target application's actual transport, authentication, UI, and capability
support. Test in that application, preserving the user's account/configuration.
Read review/submission requirements only when directory distribution is requested.
Do not treat a directory preference for remote hosting as a universal restriction
on local MCP clients, and do not submit merely because the server works.
