1. Record canonical repository, source path, exact ref/SHA, license, file hashes, and local adaptations for each source family. Many historical imports omit the SHA; version numbers and repository activity alone cannot establish file drift.

6. Verify copied executable helpers and representative behavior before shipping. For prompt changes, evaluate meaningful cases rather than assume a newer prompt improves outcomes.

## Method and limits

The audit read provenance notes and local Git history; checked official repositories, current releases, and pinned source snapshots; compared relevant skill/reference bytes; and inspected meaningful semantic differences. Known namespace/vendor-comment normalization was restricted to the documented .NET transformation. Source archives, raw comparison hashes/diffs, and detailed research notes are retained in this conversation's evidence storage. No downloaded scripts, skill installers, model evaluations, live browser jobs, or app build/release pipelines were run. The recommendations are engineering judgments from source differences, not measured prompt-performance gains or a current-law review of the legal skills.
