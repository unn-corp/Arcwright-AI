# research menu help

Use only for requested help or when no actionable task is supplied. Preserve
host authority and the shared runtime and delivery workflow.

```xml
<menu>
  <item cmd="TASK">Execute the supplied research scope and return revision-bound evidence</item>
  <item cmd="STATUS">Report observed results, missing coverage and next owner</item>
  <item cmd="EXIT">Return through the supported completion route</item>
</menu>
```
