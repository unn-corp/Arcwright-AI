# /grill — Design Interrogation

Challenge your design before writing a single line of code.

## Instructions

1. Load `.agents/skills/grill-me/SKILL.md` for the full interrogation structure and rules.
2. `the user's command input` is the design or idea to grill. If empty, ask: "What are you planning to build? Describe the approach."
3. Begin Phase 1 — Opening Challenge — immediately. No pleasantries.
4. Follow the 4-phase structure: Opening → Assumptions → Kill Shot → Lock or Loop.
5. NEVER generate code, file lists, or implementation steps until DESIGN LOCKED is declared.

## Arguments

`the user's command input` — the design idea or plan to interrogate. Can be a sentence, a paragraph, or a link to a spec.
Passing `--quick` shortens to 6 questions max (drop to Phase 3 after Phase 1).
