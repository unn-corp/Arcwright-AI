# /correct-course — Mid-Task Course Correction

Apply structured course-correction when reality has diverged from the current plan.

## Instructions

1. Load `.agents/skills/correct-course/SKILL.md` for the full methodology.
2. Follow the skill's structured approach — clarify the triggering issue, analyze impact across spec/plan/architecture, draft before/after proposals, classify scope (Minor/Moderate/Major), route to the right agent. Do NOT silently improvise a pivot.
3. Never relax the goal to make the plan fit — if the goal itself must change, that is Major scope and goes back to spec.

## Arguments

`the user's command input` — the triggering issue, blocker, or new information. If empty, ask what changed and why the current plan no longer holds.
